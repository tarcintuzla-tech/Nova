# Contributing to NOVA
Thanks for helping! Please:
1. Open an issue before large changes.
2. Run `npm run typecheck`, `npm run lint` and `npm test` before a pull request.
3. Keep UI text in `src/i18n/locales/tr.json` **and** `en.json` (a test checks both match).
4. Content must be original, accurate and clearly labelled *fact* or *interpretation*. Do not present psychology exercises as diagnosis or body-language readings as certain.
5. Do not add analytics, ads, tracking or network calls without a prior discussion.
6. Database changes need a new migration in `src/db/migrations.ts` and a test.
By contributing you agree your work is licensed under the project license.
